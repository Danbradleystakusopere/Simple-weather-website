About Weather Now

Weather Now is your go-to application for real-time weather updates.

Our Mission

We aim to provide fast, accurate, and easy-to-understand weather data using modern web technologies.

Features

  • Current weather by city
  • Humidity and wind data
  • Responsive design for mobile and desktop

Technology Used

  • HTML, CSS, and JavaScript
  • OpenWeatherMap API
